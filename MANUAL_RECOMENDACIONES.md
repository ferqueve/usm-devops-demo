# Manual de Usuario - Sistema de Recomendaciones

## Introducción

El sistema de recomendaciones inteligentes te ayuda a tomar mejores decisiones al crear reservas, gestionar inventario y asignar recursos. Las recomendaciones se basan en tu historial, patrones de uso y disponibilidad actual.

## Recomendaciones para Docentes

### Al Crear una Reserva

Cuando estás creando una nueva reserva, el sistema te mostrará:

1. **Espacios Recomendados**
   - Aparecen después de seleccionar fecha y hora
   - Muestra espacios que has usado frecuentemente
   - Considera la capacidad que necesitas
   - Incluye un porcentaje de relevancia

   **Cómo usar**: Haz clic en un espacio recomendado para seleccionarlo automáticamente.

2. **Horarios Recomendados**
   - Aparecen después de seleccionar un espacio y fecha
   - Muestra horarios que sueles usar
   - Indica disponibilidad en tiempo real
   - Incluye porcentaje de relevancia

   **Cómo usar**: Haz clic en un horario recomendado para aplicarlo automáticamente.

3. **Items Recomendados**
   - Aparecen después de seleccionar un espacio
   - Muestra items que se solicitan frecuentemente en ese espacio
   - Indica disponibilidad actual
   - Permite agregar con un clic

   **Cómo usar**: Haz clic en "Agregar" para incluir el item en tu solicitud.

### En el Dashboard

Tu dashboard personalizado muestra:
- Espacios recomendados para la próxima semana
- Items que podrías necesitar

## Recomendaciones para Analistas

### Reservas Prioritarias

En tu dashboard verás:
- Reservas que requieren atención urgente
- Ordenadas por urgencia (1-10)
- Incluye días pendientes y días hasta inicio

**Cómo usar**: Revisa primero las reservas con mayor urgencia.

### Asignación de Analista

Cuando un administrador asigna un analista a un docente, el sistema recomienda:
- Analistas que ya trabajaron con ese docente
- Analistas con menor carga de trabajo
- Analistas con mayor tasa de aprobación

## Recomendaciones para Mantenimiento

### Items que Requieren Mantenimiento

El sistema identifica:
- Items en mantenimiento hace más de 7 días
- Items dañados que necesitan reparación
- Ordenados por urgencia

**Cómo usar**: Revisa primero los items con mayor urgencia.

### Espacios que Requieren Atención

Muestra espacios con:
- Alto porcentaje de items dañados o en mantenimiento
- Necesidad de revisión general

**Cómo usar**: Visita estos espacios para realizar mantenimiento preventivo.

## Recomendaciones para Administradores

### Todas las Recomendaciones

Como administrador, tienes acceso a:
- Todas las recomendaciones de mantenimiento
- Recomendaciones de reasignación de items
- Recomendaciones de compras necesarias
- Recomendaciones de optimización de recursos

### Reasignación de Items

El sistema recomienda:
- Items sin asignar que se solicitan frecuentemente en ciertos espacios
- Mejor ubicación según patrones de uso

**Cómo usar**: Revisa las recomendaciones y reasigna items según necesidad.

### Compras Necesarias

Identifica:
- Items con alta demanda y bajo stock
- Cantidad recomendada a comprar
- Frecuencia de uso

**Cómo usar**: Usa estas recomendaciones para planificar compras.

## Entendiendo los Puntajes

Los recomendaciones incluyen un porcentaje de relevancia:

- **80-100%**: Muy relevante, altamente recomendado
- **60-79%**: Relevante, buena opción
- **40-59%**: Moderadamente relevante
- **0-39%**: Menos relevante, pero disponible

## Preguntas Frecuentes

### ¿Por qué no veo recomendaciones?

- Asegúrate de tener un historial de uso (reservas anteriores)
- Verifica que hay espacios/items disponibles
- Las recomendaciones aparecen después de seleccionar ciertos campos

### ¿Las recomendaciones son obligatorias?

No, son solo sugerencias. Puedes seleccionar cualquier opción disponible.

### ¿Cómo se actualizan las recomendaciones?

- Se actualizan automáticamente cada 30 minutos
- Se recalculan cuando creas o cancelas reservas
- Se actualizan en batch durante la noche

### ¿Puedo desactivar las recomendaciones?

No hay opción para desactivarlas, pero puedes ignorarlas si prefieres seleccionar manualmente.

## Consejos de Uso

1. **Confía en las recomendaciones**: Se basan en tu historial y patrones de uso
2. **Revisa el porcentaje**: Mayor porcentaje = mayor relevancia
3. **Usa horarios recomendados**: Suelen ser más convenientes y disponibles
4. **Agrega items recomendados**: Ahorran tiempo y suelen ser necesarios
5. **Revisa mantenimiento**: Previene problemas futuros

## Soporte

Si tienes preguntas o problemas con las recomendaciones:
- Contacta al administrador del sistema
- Revisa los logs si eres administrador
- Las recomendaciones mejoran con el tiempo y más uso
